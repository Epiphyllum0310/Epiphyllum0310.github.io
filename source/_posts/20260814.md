### 一、增加LED后的 MCU GPIO：电阻的作用

假设 STM32 已经配置成了 PA5： MODER = Output、OTYPER = Push-Pull、ODR5=1，那么 GPIO 内部上管导通、下管关闭，PA5 $\approx 3.3V$，但这样并不代表着产生电流。加上LED后，比如最常见的`PA5——电阻——LED——GND`，于是完整的链路是：

```
STM32 内部——VDD 3.3V——GPIO上管——PA5——电阻——LED——GND——电源负端
```

这里的电流就会从 VDD 一路流向 GND。值得注意的是，微控制器 LED 常见电流单位是 mA，1 mA = 0.001 A。分析电流大小：如果暂时不考虑 LED ，只看一个普通电阻 `3.3V——R——GND`，这时适用于理想线性电阻的欧姆定律$V=IR$。对于 LED ，由于 LED 属于非线性半导体器件（物理上 LED 属于 PN 结，依靠载流子复合发光，由于 PN 结正向导通后，内部势垒高度基本固定，所以外部施加克服势垒的电压也就基本固定，此时增加电流只是注入更多的载流子而已），LED 导通后会维持近似恒定正向压降$V_F$，此时电阻满足基尔霍夫电压定律
$$
R≈\frac{V_{DD} −V_F}{I}
$$
![LED伏安曲线](/images/embedded/20260814/LED伏安曲线.png)

这也就解释了为什么 **GPIO 不能忽略限流电阻而直接接到 LED 上**：由于 MCU 输出高电平 $V_{CC}$ 时，LED 只要超过开启电压就会导通，此时微小的电压上升会带来电流的大量飙升，最终烧毁器件。串联电阻后，可以承担剩余电压$V_{CC}-V_F$。

这里需要额外注意，由于 GPIO 输出电流有限，常见的 MCU 单引脚最大只有 10~25 mA，所以设计电流有最大限制，一般有两种接 LED 的方法：

1. 灌电流接法（推荐）：GPIO 输出低电平点亮 LED；
2. 拉电流接法： GPIO 输出高电平点亮 LED， 但很多 MCU 高电平的驱动能力更弱。

### 二、为什么输入引脚不能悬空：阻抗与上拉下拉

对于 GPIO 的输入模式，即 MODER：PA0 = Input，此时 GPIO 的输出驱动部分基本不参与普通输出，而是主要使用输入路径：

```
外部电路电压信号
       │
       ▼
      PA0引脚 ────┐
                  │
                  ▼
           输入缓冲器（施密特触发器）
                  │
                  ▼
           电平判决：
               高电平 → 逻辑1
               低电平 → 逻辑0
                  │
                  ▼
           IDR寄存器 bit0
                  │
                  ▼
               CPU读取
```

也就是说输入路径是在问 PA0 这个引脚电压被输入电路判断为 0 还是 1。 值得注意的是，高电平的定义是有不确定性的，在 [0,3.3V]的区间内， 一般存在一个不确定区 $(V_{IL},V_{IH})$，不在这个不确定区内的要么明确为 HIGH 要么明确为 LOW，具体数值因 STM32 型号、供电电压和引脚类型而不同，要看 datasheet。

假设 PA0 是输入状态，此时一般不会令大量电流从 3.3 V 流进 PA0，因为 MCU 的 CMOS 数字输入端被设计成**高输入阻抗**，否则为了读取一个逻辑值就要消耗大量毫安。但是高输入阻抗也带来一个副作用，也就是：**虽然 GPIO 很容易被驱动，但当无驱动时，GPIO 容易被微小干扰影响。**假设 PA0 处于 Floating 也就是什么都不接，此时没有任何电路明确规定 PA0 应当是多少伏，而现实中不存在完美隔离，即使 PA0 没有主动连接任何东西，仍然存在着各种耦合因素，比如附近电线、人体、电源开关噪声和内部漏电流。

我们可以把 Floating 输入理解成很小的电容，真实的 GPIO 输入端存在寄生电容，所以 PA0 可以暂时存一点电荷，根据 $Q=CV$，如果 C 很小，那么非常小的 $\Delta Q$ 就会引起很大的 $\Delta V$。所以悬空输入可能被手靠近、周围数字信号切换、PCB 邻线等行为缓慢充电或放电，于是 PA0 电压就会大致呈这样的变化：

```
PA0 电压

3.3V |       /¯¯¯\      /¯\
     |      /     \____/   \
2V   | ----数字阈值------------
     |   /\      /
1V   |__/  \____/
     |
0V   +------------------------→ 时间
```

只要超过输入阈值 IDR，就会使得逻辑值改变（ 0 变为 1 或者 1 变为 0 ），所以程序上会看到乱跳。解决这一乱跳现象的最直接思路是人为设定一个默认状态，即*当没人管的时候，我希望 PA0 默认是1*。按照这个思路，就可以设计 **VDD +上拉电阻**的结构：

                 VDD = 3.3V
                     │
                    [R]
                     │
                     ├──── PA0
                     │
                  [按钮]
                     │
                    GND

当不按按钮的时候， PA0 虽然通过电阻接到 VDD 上，但 GPIO 输入几乎不吸电流，因此 $I\approx0$，因此电阻压降$V_R \approx 0$，故$V_{PA0}\approx 3.3V$，此时 IDR0 = 1。（按钮松开的时候，读1）

当按下按钮的时候，PA0 被按钮通过很低的电阻直接接到 GND 上，所以 $V_{PA0}\approx 0V$，此时  IDR0 = 0.（按钮按下的时候，读 0 ）。由于此时存在上拉电阻，所以不会导致短路。所以上拉电阻实际上完成了两件事：

1. 按钮松开时给 PA0 一个确定的默认高电平；
2. 按钮按下时限制 VDD → GND 的电流。

下拉则是完全镜像的情况：

             PA0
              │
              ├──── 外部开关 ─── 3.3V
              │
             [R]
              │
             GND

按钮松开，IDR0 = 0；按钮按下， IDR0 = 1。工程上，会大量见到`VDD——上拉——GPIO——BUTTON——GND`的结构，原因是 GND 到处都有而且用按钮把输入直接拉到地非常简单。所以这样的结构是常见的：

```c++
if (!(GPIOA->IDR & BUTTON_PIN))
{
    // button pressed
}
```

代码表示读取引脚当前所有输入电平，按位与，只保留按键对应的那一位，其余位清零，若引脚 bit = 0 ，判定按键按下。这就是 **Active-Low 低电平有效**。对于 STM32 ，已经把上拉/下拉焊进了芯片，其由 PUPDR 弱上拉电阻控制，这与前文的输出开漏模式是一致的。一般的内部上拉电阻是几十 $k\Omega$ 量级的，具体需要看对应的 datasheet。

### 三、电容、RC 与去耦的直觉

#### 1. 电容与 RC 电路

一个最理想的平行板电容器是由两个金属板和绝缘介质组成，理想电容的基本定义是 $Q = CV_C$，Q 为两极板存储的电荷量，C 为电容量（单位法拉），V 为两端电压。电容在两个导体上形成电荷分离，并在两者之间建立电场，它所存储的能量位于电场中：$E=\frac{1}{2} C V_C^2$。将理想电容带入电流定义式，则瞬时电流满足
$$
i_C= C\frac{\mathrm dV_C}{\mathrm dt}
$$
所以如果希望电容电压变化的极快，就需要极大的瞬时电流。因此在不存在理想冲激电流的正常电路中，电容电压不能瞬间突变。不能瞬时跳变即通常约定
$$
V_C(0^-)=V_C(0^+)
$$
现在考虑一个最基本的RC电路：

<img src="/images/embedded/20260814/RC电路.png"
     alt="RC电路"
     style="zoom: 25%;" />

输出取在电容两侧$V_{out}=V_C$，假设一开始$V_C(0) = 0$，然后一开始在 $t = 0$ 时把输入突然从 0V 提高到恒定的 $V_S$。根据基尔霍夫电压定律：
$$
V_S=V_R+V_C=iR+V_C=RC\frac{\mathrm d V_C}{\mathrm dt}+V_C
$$
这就是一阶 RC 电路的微分方程，可以写为这样的形式：
$$
\frac{\mathrm d V_C}{\mathrm dt}=\frac{V_S-V_C}{RC}
$$
这个等式说明了，电容电压上升的速度，正比于电源电压和当前电容电压的差。当一开始$V_C = 0$的时候，速度最大，电源充电一会后$V_C$增大， 于是充电速度变慢。根据一阶 RC 电路的微分方程可解得电容电压表达式
$$
V_C(t)=V_S[1-e^{-\frac{t}{RC}}]
$$
若初始电压一般化为$V_0$，则电容电压的一般式为
$$
V_C(t)=V_S+(V_0-V_S)e^{-\frac{t}{RC}}
$$
定义时间常数 $\tau =RC$，此时 $V_C(\tau)=V_S(1-e^{-1})\approx 0.6321 V_S$，也就是说每经过$\tau$，距离最终值的剩余误差变为原来的 36.8%，因此：

| 经过时间  | 误差剩余量     |
| --------- | -------------- |
| $t=\tau$  | 36.8% 误差剩余 |
| $t=2\tau$ | 13.5% 误差剩余 |
| $t=3\tau$ | 5.0% 误差剩余  |
| $t=5\tau$ | 0.67% 误差剩余 |

所以工程上常说 $5\tau$ **后基本稳定**，此时已经达到最终值的约99.33%。假设电容开始时 $V_C(0)=V_0$，然后通过电阻接地：`V_C——C——R——GND`，此时最终值$V_\infty =0$，这说明了 RC 放电本质上也是符合电容电压表达式的。

#### 2. 按键消抖

频域上可以理解为何 RC 电路是低通滤波器：正弦稳态下，电容等效阻抗为
$$
Z_C=\frac{1}{j\omega C},\omega=2\pi f
$$
角频率越高，电容阻抗越小。整个电路中 R 与 $Z_C$ 串联，构成分压电路，那么整个 RC 电路的传递函数为
$$
H(j\omega)=\frac{V_{out}}{V_{in}}=\frac{Z_C}{R+Z_C}
=\dfrac{\dfrac{1}{j\omega C}}{R+\dfrac{1}{j\omega C}}
=\frac{1}{1+j\omega RC}\
$$
其幅值为
$$
\abs{H}=\frac{1}{\sqrt{1+(\omega RC)^2}}
$$
当$\omega\to 0$时，$\abs{H}\to 1$，此时低频基本通过；当$\omega\to \infty$时，$\abs{H}\to 0$，此时高频基本滤除，所以上述探讨的 一阶 RC 电路即是**一阶 RC 低通滤波器**。

记 $A(\omega)=\abs{H(j\omega)}$ 为幅值增益，定义角截止频率 $\omega_C$ 满足$A(\omega_C)=\frac{A_{max}}{\sqrt 2}$，换算成分贝则有
$$
20\lg A(\omega_C)-20\lg A_{max} = 20 \lg \frac{1}{\sqrt 2} \approx -3.01\mathrm{dB}
$$
所以角截止频率又称 -3 dB 截止频率。因\(P\propto V^2\implies \frac{P(\omega_c)}{P_{\text{max}}}=\left(\frac{1}{\sqrt{2}}\right)^2=\frac12\)，所以也称半功率点。将截止频率代入 RC 低通电路，解得 $\omega_C RC=1$，所以截止频率为
$$
f_C=\frac{1}{2\pi RC}
$$
机械开关接触时，真实发生若干快速跳变而非单次跃迁，单次跳变可能持续若干毫秒，对于 MCU 来说足够发生几十万次计的指令周期，所以**一次机械按键可能就会被检测为多次按键**。

假设按钮通过 RC 形成，组成这样的结构：

```
VDD
 │
 R
 │
 ├──── GPIO
 │
 C
 │
GND
```

那么短时间的接触意味着在较短时间内，输入发生多次来回变化，如果这些变化时间满足$T_{\mathrm {bounce}} \gg RC\equiv \tau$，那么电容电压来不及充放电跟随瞬时跳变，此时 GPIO 上实际看到的模拟电压更加的平滑。但值得注意的是，RC 只是把机械抖动变为了较慢且平滑的模拟变化，而非自己产生一个完美数字边沿，所以硬件消抖通常最好还需要配合 **Schmitt Trigger 施密特触发器**或者 MCU 自己的软件延时。

普通的数字输入如果只有一个阈值 $V_T$，当输入电压恰好在阈值附近带噪声的时候，可能就会不断地产生 0 和 1 之间的跳变（与前文中的悬空跳变相同）。施密特输入使用两个阈值，将两个阈值中间的区间作为 hysteresis 滞回区，只有超过两个阈值时才会判断逻辑，这在前面也有所应用。

#### 3. 去耦电容

去耦电容的工作原理与简单的 RC 低通不同，真正的 MCU 供电网络更像是

```
理想电源
   │
  Rwire（VDD走线电阻）
   │
  Lwire（VDD走线寄生电感）
   │
   ├──────── MCU VDD 引脚
   │          │
   │        MCU负载（包含所有GPIO模块）——GND
   │          
   │         
   │
  Cdec（去耦电容）
   │
  GND
```

其中有电源本身输出阻抗、PCB 走线同时存在寄生电阻\(R_\mathrm{wire}\)、寄生电感\(L_\mathrm{wire}\)与寄生电容、电容 ESR、电容 ESL、MCU 动态负载等等，所以这已经是一个**电源分配网络 PDN**，而非一个单纯的 RC。

> 【注】：PDN 网络容易和之前的 GPIO 网络混淆，实际上整个 MCU 网络是这样的设计：
>
> ```
> 外部电源 → Rwire、Lwire → MCU VDD引脚
>                                  │
>                          芯片内部电源网络
>                                  │
>                          ┌──────┴──────┐
>                          ▼             ▼
>                 CPU/SRAM/Flash     GPIOA模块
>                                        │
>                          PA0、PA1、PA2 ...（外部信号引脚）
> ```
>
> GPIO 模块依靠 VDD 供电，这里需要简单介绍一下VDD。VDD（Drain） 起源于 CMOS 集成电路，**VDD是芯片的正电源供电电压**，给内部 MOS 管漏极供电，对应的负电位参考是VSS（Source 源极，通常接 GND）。VDD的适用范围为现代 MCU、FPGA、数字 CMOS 芯片，现在的STM32、GD32、ESP32均采用这套结构。
>
> 而 VCC 则是起源于双极型晶体管（BJT）时代，作为 BJT 电路集电极供电正电源，对应的是负极 $V_{EE}$。该电源目前常用于传统的 51 单片机、TTL逻辑、模拟 BJT 电路、老教科书中。

MCU 内部为 CMOS 数字电路，逻辑门、金属互连线本身存在寄生负载电容\(C_L\)。如果一个节点等效电容是 $C_L$，从 $0 \to V_{DD}$变化，需要增加的电荷量为$\Delta Q = C_L V_{DD}$。当 CPU、SRAM、总线、外设（Flash、GPIO、定时器）大量晶体管同时翻转（即电平高变低、低变高的翻转）时，会同时产生大量电荷需求，形成**瞬态脉冲电流**。因此 MCU 供电电流并非恒定直流，而是在平均电流基础上叠加大量高速变化的电流脉冲。

当 MCU 瞬时需要额外电流\(\Delta I\)时，电流变化速率\(\dfrac{di}{dt}\)很大。PCB 走线寄生电感满足电感伏安特性
$$
V_L=L\frac{\mathrm di}{\mathrm dt}
$$
电感具有阻碍电流突变的特性，电流快速上升时，电感上将产生可观感应电压。沿供电回路列 KVL 可知：远端电源电压一部分降落在走线寄生电感上，直接造成 MCU 芯片\(V_{DD}\)引脚电压暂时性跌落，产生电源噪声。

这时候就发挥了去耦电容的作用。当稳态时，去耦电容两端电压被充至$V_{DD}$， 此时去耦电容存储的电场能量为
$$
E=\frac{1}{2} CV_{DD}^2
$$
由电容伏安特性在短时间的离散形式：
$$
i\approx C\frac{\Delta V}{\Delta t}\Rightarrow \Delta V\approx \frac{\Delta I \cdot \Delta t}{C}
$$
式中 $\Delta I$ 为 MCU  所需瞬态电流，$\Delta t$ 为电流持续时间，$\Delta V$为电容电压跌落。那么随着电容容量 C 越大，电压跌落$\Delta V$ 就会越小。去耦电容作为本地电荷池，瞬时提供突变负载电流，维持 MCU 引脚\(V_{DD}\)稳定，**抑制电源扰动。**这里的去耦 Decoupling 可以理解为：尽量不让某个电路产生的快速电流扰动，通过公共电源网络影响其他电路。

值得注意的是，**去耦电容一定要靠近 VDD 引脚**，这是因为虽然从结构上看是`VDD——C——GND`，但 PCB 铜箔走线存在寄生电感，环路越长、走线面积越大、环路总寄生电感 $L$ 越大。电感会阻碍电流快速变化（根据伏安特性），最终抵消电容稳压的效果。

工程中可以对去耦电容产生一些粗略的直觉：

- 100 nF 小陶瓷：处理更快、更局部的瞬态；
- 1-10 $\mu F$：较低频、较大能量缓冲；
- 更大 bulk capacitor：更慢的供电变化。
